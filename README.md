## Installation
```bash
git clone https://ZaraGoza1303/bspwm-dotfiles.git
cd bspwm-dotfiles
./install.sh
```

## **GTK theme download in [gnome-look](https://www.gnome-look.org/browse/)**
For Example i'm using this gtk theme [Nordic-darker](https://www.gnome-look.org/p/1267246/)
After you complete download it, extract the folder and then copy the folder to **/usr/share/themes**

## **Betterlockscreen init walpaper**
U need to init the walpaper for betterlockscreen

#### **Init Betterlockscreen**
```bash
betterlockscreen -u path/to/img.jpg
```
